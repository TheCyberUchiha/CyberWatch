Capabilities

What CyberWatch Monitors

Every feature is real, tested, and validated on Windows 10 and 11. No invented capabilities — only what actually ships.

Screen Lock Detection

Detects Windows screen lock events via the WTS Session Notification API. Records timestamp and session context to the local SQLite database instantly.

Screen Unlock Detection

Captures screen unlock events via WTS notifications and immediately dispatches an email alert — notifying you the moment your session becomes accessible.

Agent Startup & Shutdown

Self-reports its own startup and graceful shutdown events. Lets you confirm the agent is alive and track any unexpected interruptions in your event history.

Restart & Shutdown Recovery

Reads Windows Event Log (ID 1074 graceful, ID 6008 unexpected) on startup, detecting system events that occurred while the agent was offline.

SQLite Event Persistence

Every security event is stored in a local SQLite database (WAL mode) on your machine. No cloud uploads. Full event history remains private and on-device.

Email Notifications

Sends real-time SMTP email alerts with clean HTML and plain-text templates. Works with Gmail App Passwords or any standard SMTP server with STARTTLS/TLS.

Duplicate-Event Suppression

A configurable deduplication filter prevents sending multiple alerts for the same event type within a defined window. Eliminates notification storms.

SMTP Retry Handling

Automatically retries failed SMTP connections with exponential back-off (5s → 30s → 120s). Transient network issues never silently drop an alert.

Structured Logging

Produces rotating, structured log files for all agent activity. Easily readable in any text editor. Start Menu shortcut opens logs directly in Notepad.

Automatic Windows Startup

Registers itself in Windows Task Scheduler with an "At Logon" trigger. No administrator rights required. Starts silently whenever you sign in to Windows.

Fully Local Monitoring

All event collection, storage, and processing happens locally on your Windows machine. No data leaves your device except the SMTP email to your own inbox.

Windows Event Log Integration

Integrates directly with the Windows Event Log subsystem for system-level events (shutdown, restart, unexpected power-off) via native Win32 APIs.

Architecture

How CyberWatch Works

A lightweight background agent collects Windows security events, normalises them through an internal event bus, stores each record in a local SQLite database, and dispatches email notifications — all without a network call except to your own SMTP server.

Read Architecture Docs →

01 — Source

Windows Events

WTS Session notifications and Windows Event Log (IDs 1074, 6008) provide the raw event stream from the operating system.

02 — Collect

Collectors

Specialised collectors (wts_session, system_events, lifecycle) listen for their respective event types and publish normalised EventRecord objects.

03 — Filter

EventBus + Dedup

The EventBus dispatches events to all subscribers. A deduplication filter suppresses identical events within a configurable time window.

04 — Store

SQLite Database

DatabaseHandler persists every event to a local SQLite DB (WAL mode). Records include full metadata and email delivery status.

05 — Notify

Email Notifier

EmailNotifier delivers alerts via SMTP/TLS with exponential back-off retry. Failures are logged and the event is flagged in the database.

06 — Delivered

Your Inbox

You receive a clean, formatted security alert email — the only data that ever leaves your machine, sent directly to your own inbox.

Privacy First

Designed for Transparency

CyberWatch is built around session-level event monitoring — not content surveillance. Here is exactly what it does and does not access.

What CyberWatch Does NOT Capture

  • ✕Keystrokes or typed input
  • ✕Passwords or credentials
  • ✕Clipboard contents
  • ✕Screenshots or screen recordings
  • ✕Browser history or web activity
  • ✕Webcam or microphone
  • ✕File access or application usage
  • ✕Network traffic

What CyberWatch Does Capture

  • ✓ Event type (LOCK, UNLOCK, SHUTDOWN…)
  • ✓ Timestamp (local + UTC)
  • ✓ Windows username
  • ✓ Computer name
  • ✓ Windows Session ID
  • ✓ Windows Event ID and source

Your Gmail App Password is stored only in the local .env file on your device. It is never written to logs, never sent to any CyberWatch server (none exists), and never included in the installer binary. Never share your App Password with anyone.

Setup

Installation Guide

CyberWatch installs in under two minutes. You only need a Gmail account with two-step verification to send yourself alerts.

01

Download CyberWatch

Click Download CyberWatch for Windows above to download CyberWatch-Setup.exe — a single-file Windows installer (~9 MB). No Python or additional software required.

02

Run the Installer

Double-click CyberWatch-Setup.exe. If Windows SmartScreen appears, click "More info" → "Run anyway". The installer does not require administrator rights.

03

Enter Your Notification Settings

The installer will ask for three things: your recipient email address (where alerts are sent), your Gmail address (the sender), and your Gmail App Password (16 characters from Google Account → Security → App Passwords).

⚠️ Your Gmail App Password is yours alone. Never share it with anyone, including the developer of this software. It is stored locally on your machine and never transmitted to any CyberWatch server.
04

Complete Installation

Click through to complete. CyberWatch is installed to %LOCALAPPDATA%\Programs\CyberWatch and a Windows Task Scheduler task (CyberWatch_Agent) is created automatically. Start Menu shortcuts are added for Configure, Test Email, and View Logs.

05

Send a Test Email

At the end of installation, tick "Send a test notification email now" to verify your SMTP credentials are working. Check your inbox for a test alert. If no email arrives, use Start Menu → CyberWatch → Test Email Notification and check the log at Start Menu → CyberWatch → View Logs.

06

You're Done

CyberWatch runs automatically every time you log in to Windows. Lock your screen — you'll receive an alert. Unlock it — another alert. The agent runs silently in the background with no visible window.
