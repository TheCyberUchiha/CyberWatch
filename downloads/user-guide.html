CyberWatch

Quick Setup Guide · Personal Windows Security Monitor

What CyberWatch Does

CyberWatch is a personal security monitoring tool for your Windows laptop. It monitors Windows session lock/unlock and system startup/shutdown events, records them to a private local database on your computer, and sends you instant email alerts.

  • ✅ Monitors: Windows screen Lock, screen Unlock, system Shutdown, Restart
  • ✅ Alerts: Sends instant email to your inbox
  • ✅ Local: All records stay on your computer — no cloud uploads

What CyberWatch does NOT do:

No keystroke logging
No password capture
No screenshots
No browser history
No webcam/microphone
No cloud telemetry

1 Create a Gmail App Password (~2 minutes)

CyberWatch sends alerts via Gmail. You need a special 16-character code called an App Password (not your regular Gmail password).

  1. Go to myaccount.google.com
  2. Click Security → ensure 2-Step Verification is ON
  3. Go to App Passwords
  4. Enter name CyberWatch → click Create
  5. Copy the 16-character code shown — you'll use it in Step 2
⚠️ Keep this code private. It belongs to your Google account. Never share it with anyone. CyberWatch only uses it to send alerts to your own inbox.

2 Run the Installer

  1. Double-click CyberWatch-Setup.exe
  2. If Windows shows a SmartScreen warning: click More info → Run anyway
    (This is normal for open-source software without a paid certificate)
  3. Read the information screen and click Next
  4. Leave the installation folder as default → click Next
  5. On the configuration screen, enter:
    • Notification Recipient Email — where you want to receive alerts
    • SMTP User / Gmail Address — the Gmail account that sends alerts
    • Gmail App Password — the 16-character code from Step 1
  6. Click Next → Install
  7. On the final screen, check "Send a test notification email now" to verify setup

3 You're Done — CyberWatch is Active

CyberWatch is now running and registered in Windows Task Scheduler. It will start automatically every time you log into Windows.

You'll receive email alerts when:

  • Your screen is locked or unlocked
  • Your computer restarts or shuts down
  • CyberWatch starts or stops

Managing CyberWatch

After installation, find CyberWatch shortcuts in your Windows Start Menu:

  • Configure CyberWatch — update your email or App Password
  • Test Email Notification — send a test alert immediately
  • Check Task Status — verify the background agent is running
  • View Logs — open the event log in Notepad
  • Uninstall CyberWatch — remove the application cleanly

How to Uninstall

To remove CyberWatch:

  1. Open Windows Settings → Apps → Installed Apps
  2. Find CyberWatch → click Uninstall
  3. Or use Start → CyberWatch → Uninstall CyberWatch

The uninstaller stops the background agent, removes the Task Scheduler entry, and removes all application files.
