Installation Guide

This guide walks you through installing CyberWatch on Windows 10 or Windows 11 using the provided installer. No Python or technical knowledge required.

Quick summary: Download the EXE → Generate a Gmail App Password → Run the installer → Enter your email details → Done. CyberWatch starts automatically at every logon.

Prerequisites

Before running the installer, you need:

  • Windows 10 or Windows 11 — CyberWatch has been tested on these platforms only.
  • A Gmail account — for sending email alerts. You must enable 2-Step Verification.
  • A Gmail App Password — a 16-character code used instead of your regular password. See the section below.

Step 1 — Create a Gmail App Password

CyberWatch sends email notifications using Gmail's SMTP service. Gmail requires a dedicated App Password (separate from your regular login password) for this.

  1. Sign in to your Google Account at myaccount.google.com
  2. Click Security in the left navigation.
  3. Under "How you sign in to Google", ensure 2-Step Verification is turned on. If it's off, enable it first.
  4. Search for App passwords or visit myaccount.google.com/apppasswords.
  5. Enter an app name such as CyberWatch and click Create.
  6. Google shows a 16-character code (e.g. abcd efgh ijkl mnop). Copy this — you'll paste it during installation.
Important: This App Password grants the ability to send email from your Gmail account. Never share it with anyone. CyberWatch stores it locally on your machine with file-permission protection and never transmits it anywhere except Gmail's SMTP server.

Step 2 — Download CyberWatch

Download CyberWatch-Setup.exe from the website:

  • Download CyberWatch-Setup.exe

The installer is approximately 9 MB. It is a standard Windows installer built with Inno Setup 6.

Step 3 — Windows SmartScreen Warning

When you run CyberWatch-Setup.exe, Windows SmartScreen may display a warning:

"Windows protected your PC"

This is normal for software distributed without a paid code-signing certificate. CyberWatch is open-source — you can inspect every line of source code on GitHub.

To proceed: click More info, then click Run anyway.

Step 4 — Run the Installer

  1. Double-click CyberWatch-Setup.exe.
  2. Read the Information screen explaining what CyberWatch does and does not do.
  3. Click Next.
  4. Optionally change the installation folder. The default is: 
    %LOCALAPPDATA%\Programs\CyberWatch
    This is your personal user folder — no Administrator rights are required.
  5. Click Next to proceed to the configuration screen.

Step 5 — Configure Email Alerts

On the Alert & Notification Configuration screen, fill in:

  • Notification Recipient Email — the email address where you want to receive alert messages. This is usually your own email address.
  • SMTP User / Gmail Address — the Gmail address that will send the alerts. This is your Gmail account (the one you created the App Password for).
  • Gmail App Password — the 16-character code from Step 1. The characters are masked as you type.

Click Next, then click Install.

Step 6 — Send a Test Alert

On the final screen, check the box labeled "Send a test notification email now". CyberWatch will immediately attempt to send a test email to your configured address.

Check your inbox. If you receive the test email, your configuration is working correctly.

Tip: If the test email doesn't arrive, check your spam folder. If it's still missing, see the Troubleshooting guide.

Step 7 — CyberWatch is Active

CyberWatch is now installed and registered in Windows Task Scheduler. From this point:

  • CyberWatch starts automatically every time you log in to Windows.
  • You'll receive an email alert when your screen is locked, unlocked, or your system restarts.
  • All events are stored privately in a local SQLite database on your machine.

Start Menu Shortcuts

After installation, CyberWatch adds shortcuts to your Start Menu under CyberWatch:

  • Configure CyberWatch — re-open the configuration wizard to update your email or App Password.
  • Test Email Notification — send a test alert immediately.
  • Check Task Status — verify the background agent is running.
  • View Logs — open the event log in Notepad.
  • Uninstall CyberWatch — remove the application cleanly.

Uninstalling

To remove CyberWatch:

  1. Go to Windows Settings → Apps → Installed Apps.
  2. Find CyberWatch and click Uninstall.
  3. Alternatively, use Start → CyberWatch → Uninstall CyberWatch.

The uninstaller stops the background agent, removes the Task Scheduler entry, and removes all application files.
