CyberWatch-Setup.exe User Guide

Configuration Guide

This guide covers SMTP configuration, Gmail App Password setup, and the available advanced settings you can adjust after installation.

Gmail App Password Setup

CyberWatch uses standard SMTP with STARTTLS to send email alerts. Gmail requires an App Password — a 16-character dedicated credential — because CyberWatch is a non-browser app.

Requirements

  • A Gmail account (any personal Gmail address).
  • 2-Step Verification must be enabled on your Google Account. Without 2FA, App Passwords are not available.

Creating an App Password

  1. Go to Google Account → Security.
  2. Confirm that 2-Step Verification is enabled.
  3. Navigate to App Passwords.
  4. Enter a name like CyberWatch and click Create.
  5. Copy the displayed 16-character password.
Security reminder: Your Gmail App Password gives access to send email from your account. Never share it with anyone. Never paste it into a public forum, chat, or issue tracker. CyberWatch stores it locally, protected by Windows file permissions.

Re-configuring After Installation

If you need to update your notification email or App Password after installation, use any of these methods:

Option A — Start Menu

Open Start → CyberWatch → Configure CyberWatch. The configuration wizard reopens and you can update any field.

Option B — Command Line

cd "%LOCALAPPDATA%\Programs\CyberWatch"
cyberwatch_cli.exe configure

Option C — Silent Update

cyberwatch_cli.exe configure --email "alerts@example.com" --smtp-user "sender@gmail.com" --smtp-pass "abcdefghijklmnop"

Sending a Test Email

To verify your SMTP configuration at any time:

cyberwatch_cli.exe test-email

Or use Start → CyberWatch → Test Email Notification.

Advanced Settings

All settings are stored in a .env file in the installation directory. You can edit them with any text editor. Below is the complete configuration reference.

Caution: Edit the .env file only if you understand what you're changing. Incorrect SMTP settings will prevent email delivery.
Key Default Description
SMTP_HOST — SMTP server hostname (e.g. smtp.gmail.com)
SMTP_PORT 587 587 for STARTTLS, 465 for SSL
SMTP_USE_TLS true Use STARTTLS encryption
SMTP_USER — Sender Gmail address
SMTP_PASSWORD — Gmail App Password (16 chars)
NOTIFY_EMAIL — Recipient email for alerts
DEDUP_WINDOW_SECONDS 60 Suppress duplicate events within this window
EMAIL_COOLDOWN_SECONDS 30 Minimum gap between same-type emails
EMAIL_RETRY_MAX 3 SMTP retry attempts per event
LOG_LEVEL INFO Logging verbosity (DEBUG, INFO, WARNING, ERROR)

Windows Task Scheduler

CyberWatch registers itself as a Task Scheduler task named CyberWatch_Agent with an At Logon trigger. You can manage it with:

# Check status
schtasks /Query /TN CyberWatch_Agent /FO LIST

# Start manually
schtasks /Run /TN CyberWatch_Agent

# Stop
schtasks /End /TN CyberWatch_Agent
