Troubleshooting

Common issues and their solutions. Start by checking the log file for error messages:

  • Start Menu: Start → CyberWatch → View Logs
  • Direct path: %LOCALAPPDATA%\Programs\CyberWatch\logs\cyberwatch.log

No Emails Received

1. Check your spam folder

Gmail-to-Gmail alerts sometimes land in spam. Mark the email as "Not spam" to train your inbox filter.

2. Verify your App Password

The App Password must be exactly 16 characters (spaces are optional). Verify it hasn't been revoked in your Google Account security settings.

3. Confirm 2-Step Verification is still enabled

If you disabled 2FA on your Google account after creating the App Password, the App Password is automatically revoked. Re-enable 2FA and create a new App Password.

4. Test SMTP connectivity manually

Use the built-in test command:

cd "%LOCALAPPDATA%\Programs\CyberWatch"
cyberwatch_cli.exe test-email

Check the output and the log file for specific SMTP error messages.

5. Verify network access to smtp.gmail.com

Some corporate or school networks block outbound SMTP. Try from a home network. Port 587 must be accessible.

Lock / Unlock Not Detected

1. Ensure CyberWatch is running in your interactive session

CyberWatch must run in the same Windows session as your logged-in user to receive WTS notifications. It must NOT be running as a SYSTEM-level Windows Service — it uses Task Scheduler with an "At Logon" trigger in your user context.

2. Check Task Scheduler

schtasks /Query /TN CyberWatch_Agent /FO LIST

Confirm the task is listed, enabled, and the "Run As User" is your user account (not SYSTEM).

3. Start the task manually to test

schtasks /Run /TN CyberWatch_Agent

Then lock and unlock your screen. Check the log file for LOCK and UNLOCK event entries.

4. Antivirus interference

Some antivirus products may block applications from registering WTS notification listeners. Add the CyberWatch installation folder as an exclusion if you suspect this.

Agent Not Starting Automatically

1. Verify the Task Scheduler task exists

schtasks /Query /TN CyberWatch_Agent

If the task is not found, re-run the configuration wizard from the Start Menu to re-register it.

2. Check the task trigger

Open Task Scheduler (search for it in the Start Menu), find CyberWatch_Agent, and confirm the trigger is "At log on" for your user account.

3. Run the agent manually

cd "%LOCALAPPDATA%\Programs\CyberWatch"
cyberwatch_agent.exe

Any startup errors will appear in the console or log file.

Shutdown / Restart Events Not Logged

Windows Event ID 1074 only appears in the Event Log for graceful shutdowns initiated via the Start Menu or the shutdown command. Hard power-off events (unplugging power, battery removal) do not produce Event 1074. They appear as Event ID 6008 ("unexpected shutdown") on the next boot.

CyberWatch reads both events correctly. If you performed a graceful restart and no event was logged, check the application log for Windows Event Log access errors.

Installer Blocked by Antivirus

As an unsigned installer, CyberWatch-Setup.exe may be quarantined by some antivirus products. Options:

  1. Temporarily disable real-time protection during installation only.
  2. Add the downloaded file as an exclusion before running it.
  3. Build from source yourself: see the GitHub repository for build instructions.

Re-opening Configuration Wizard

If you need to update your email credentials:

cd "%LOCALAPPDATA%\Programs\CyberWatch"
cyberwatch_cli.exe configure

Or use Start → CyberWatch → Configure CyberWatch.
