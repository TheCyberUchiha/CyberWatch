Frequently Asked Questions

Answers to the most common questions about CyberWatch.

Privacy & Safety

Does CyberWatch spy on me?

No. CyberWatch monitors only operating system–level session events (lock, unlock, logon, logoff, shutdown, restart). It does not access any user content, keystrokes, passwords, files, browser history, webcam, microphone, or clipboard.

All source code is available on GitHub for independent verification.

Is my email password stored safely?

CyberWatch stores your Gmail App Password in a local .env file protected by Windows file permissions (owner-only read/write). It is never written to log files and never transmitted to any server except Gmail's SMTP server (smtp.gmail.com:587) over an encrypted TLS connection.

You should use a Gmail App Password — not your regular Gmail password. App Passwords can be revoked independently without affecting your Google account login.

Does CyberWatch send my data anywhere?

The only outbound network connection CyberWatch makes is to Gmail's SMTP server to deliver email alerts to your own inbox. No data is sent to the developer, no analytics are collected, and there is no cloud telemetry of any kind.

Can I install CyberWatch on someone else's computer?

CyberWatch is designed for personal use on your own device. If you install it on a device you do not own, you are responsible for ensuring you have appropriate legal authorisation to run monitoring software on that device. CyberWatch was not built for surveillance of other people's computers.

Email & SMTP

Do I need a Gmail account?

Gmail is the recommended and tested email provider. CyberWatch uses standard SMTP with STARTTLS, which is supported by most email providers. If you want to use a different provider, you can edit the SMTP_HOST, SMTP_PORT, and related settings in the .env configuration file after installation.

What is a Gmail App Password and why do I need it?

Google requires App Passwords for third-party applications that send email via SMTP when 2-Step Verification is enabled. An App Password is a 16-character code that grants permission to send email from your account — without exposing your regular Google password.

App Passwords can be created and revoked independently at myaccount.google.com/apppasswords.

The notification email goes to my spam folder. How do I fix this?

Open the notification email in your inbox, click the three-dot menu, and select "Not spam" or "Move to inbox". Gmail will learn from this action and future alerts should arrive in your inbox.

Alternatively, create a Gmail filter to always deliver emails from your sender address to your inbox.

Can I send alerts to a different email address than the one sending them?

Yes. The Notification Recipient Email (where alerts are delivered) can be different from the SMTP User / Gmail Address (which sends the alerts). For example, you can send from myalerts@gmail.com to my.phone@carrier.com.

Technical

Does CyberWatch require administrator rights?

No. CyberWatch installs to your user profile folder (%LOCALAPPDATA%\Programs\CyberWatch) without requiring administrator rights. The Task Scheduler task runs as your own user account, not as SYSTEM or Administrator.

Will CyberWatch slow down my computer?

CyberWatch is a lightweight background process. It uses event-driven architecture (waiting for Windows notifications) rather than polling, which means it consumes essentially no CPU when idle. Memory usage is minimal. It should have no noticeable impact on system performance.

What Windows versions are supported?

CyberWatch has been validated on Windows 10 and Windows 11. It is not tested on Windows 7, Windows 8, or Windows Server. It is not designed for macOS or Linux.

Does CyberWatch need Python installed?

No. The distributed CyberWatch-Setup.exe is a fully self-contained installer built with PyInstaller and Inno Setup. It bundles the Python runtime and all dependencies. No separate Python installation is required.

How do I update CyberWatch?

Uninstall the current version via Windows Settings → Apps → CyberWatch → Uninstall, then install the new version. Your configuration is removed with the uninstaller, so you'll need to re-enter your email and App Password during reinstallation.

Where are the log files?

Log files are located at:

%LOCALAPPDATA%\Programs\CyberWatch\logs\cyberwatch.log

The log rotates automatically to prevent excessive disk usage. You can also open it directly from Start → CyberWatch → View Logs.
